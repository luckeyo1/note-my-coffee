# Google Play 스토어 등록용 이미지

이 폴더의 파일은 **Play Console에 수동으로 업로드**하는 스토어 등록 자산입니다.
웹에는 배포되지 않습니다(`firebase.json`의 `ignore`에 `store/**` 포함).

모든 이미지는 앱의 디자인 시스템("계측기 노트")을 그대로 따릅니다 —
종이색 `#FCFAF6`, 잉크 `#241C15`, 시그널(클레이) `#9E421D`, 한글 Pretendard,
숫자 IBM Plex Mono.

**프리미엄 프레젠테이션(v3 — 실사·연결형):** 5장의 폰 스크린샷은 **하나로 이어진
실제 추출 사진 배경**(블러·어두운 그레이딩) 위에 올려, 스토어 갤러리에서 넘길 때
한 세트처럼 연결됩니다(The Coffee 스타일). 폰은 실제 기기 프레임(베젤·측면 버튼·
유리 반사)에 담고, '공유' 패널에는 **실제 공유 카드 3장**을 부채꼴로 띄워 강조.
배경 실사와 공유 카드는 사용자의 실제 추출 사진(`src/photos/`)을 사용합니다.
피처 그래픽·태블릿도 같은 어두운 실사 톤으로 통일했습니다.

## Play Console 이미지 규격

- **앱 아이콘**: 512 × 512 PNG(32bit, 알파)
- **피처 그래픽**: 1024 × 500 PNG/JPG(투명 불가) — 정확히 이 크기
- **폰 스크린샷**: 2–8장, 16:9 또는 9:16, 변당 320–3840px. 여기선 1080 × 1920 사용
- **7"/10" 태블릿 스크린샷**: 선택. 여기선 1920 × 1080(가로) 사용

## 생성 방법(재현)

이미지는 리포지토리 루트에서 로컬 서버를 띄우고 Playwright(Chromium)로
HTML을 캡처해 만듭니다. 먼저 앱 화면(아래)을 캡처한 뒤, 그 캡처를 기기
프레임 + 프리미엄 배경이 있는 프레젠테이션 템플릿에 합성합니다. 모든 UI 문구는 한글.

1. 앱 화면 캡처
   - 기록 콘솔: `index.html`의 히어로 데모 폰을 로드 → 텍스트 노드를 한글로 치환 → 캡처.
   - 공유 카드: `brew-card.js`의 `renderBrewCanvas(..., 'ko')`로 스토리 카드 캔버스를 렌더.
   - 둘러보기/프로필/로그북: 실제 `style.css` 클래스로 구성한 목업을 캡처.
2. 프레젠테이션 합성 (v3 — 실사·연결형)
   - 폰 5장: 5400×1920 파노라마 캔버스에 **이어진 실사 배경**(`src/photos/` 4장을
     블러·어두운 그레이딩)을 깔고, 각 패널에 기기 프레임 + 캡션을 올린 뒤 1080×1920
     5장으로 잘라냅니다 → 갤러리에서 넘길 때 배경이 연결됨.
   - '공유' 패널: 실제 공유 카드 3장(`src/photos/real-*.webp`)을 부채꼴로 배치.
   - 피처 그래픽: `store/android/feature-graphic.html`(어두운 실사 + 실제 공유 카드)
     1024×500 캡처. 배경/카드 이미지는 `src/photos/real-1.webp`.
   - 태블릿: 같은 어두운 실사 톤, 기기 프레임 + 실제 카드를 가로로 배치해 1920×1080.

> 실제 추출 사진 원본은 `store/android/src/photos/`에 보관되어 있습니다.
> 문구/배경을 바꾸려면 합성 템플릿과 이 사진들을 사용해 다시 렌더하면 됩니다.
