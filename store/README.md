# Google Play 스토어 등록용 이미지

이 폴더의 파일은 **Play Console에 수동으로 업로드**하는 스토어 등록 자산입니다.
웹에는 배포되지 않습니다(`firebase.json`의 `ignore`에 `store/**` 포함).

모든 이미지는 앱의 디자인 시스템("계측기 노트")을 그대로 따릅니다 —
종이색 `#FCFAF6`, 잉크 `#241C15`, 시그널(클레이) `#9E421D`, 한글 Pretendard,
숫자 IBM Plex Mono, 은은한 기록지 괘선 배경.

## Play Console 이미지 규격

- **앱 아이콘**: 512 × 512 PNG(32bit, 알파)
- **피처 그래픽**: 1024 × 500 PNG/JPG(투명 불가) — 정확히 이 크기
- **폰 스크린샷**: 2–8장, 16:9 또는 9:16, 변당 320–3840px. 여기선 1080 × 1920 사용
- **7"/10" 태블릿 스크린샷**: 선택. 여기선 1920 × 1080(가로) 사용

## 생성 방법(재현)

이미지는 리포지토리 루트에서 로컬 서버를 띄우고 Playwright(Chromium)로
HTML을 캡처해 만듭니다. 폰 프레임은 앱의 실제 화면/목업을 캡처한 뒤
문구 프레임 위에 합성합니다. 모든 UI 문구는 한글입니다.

- 피처 그래픽: `store/android/feature-graphic.html`을 1024×500 뷰포트(배율 1)로 캡처.
- 기록 콘솔: `index.html`의 히어로 데모 폰을 로드 → 텍스트 노드를 한글로 치환 → 캡처.
- 공유 카드: `brew-card.js`의 `renderBrewCanvas(..., 'ko')`로 스토리 카드 캔버스를 렌더.
- 둘러보기/프로필/로그북: 실제 `style.css` 클래스로 구성한 목업을 캡처.

> 스크린샷 문구를 바꾸려면 캡션 텍스트만 수정 후 다시 렌더하면 됩니다.
