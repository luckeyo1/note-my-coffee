# Google Play 스토어 등록정보 — 일본어(ja-JP)

Play Console → 스토어 등록정보 → **번역 관리 → 언어 추가 → 日本語(ja-JP)** 에
아래 텍스트를 붙여넣습니다. 스크린샷·피처 그래픽은 같은 화면의 "그래픽" 섹션에서
언어별로 올릴 수 있습니다(안 올리면 기본 언어 자산으로 대체됩니다).

> 글자 수 한도: 앱 이름 30자 / 간단한 설명 80자 / 자세한 설명 4000자.

---

## アプリ名 (App title) — ≤30자

```
Note My Coffee：コーヒー抽出記録
```

(대안, 더 짧게: `Note My Coffee 抽出レシピ`)

## 簡単な説明 (Short description) — ≤80자

```
4つの数字、30秒。バリスタ品質のコーヒー抽出レシピを記録・再現・シェア。
```

## 詳細な説明 (Full description) — ≤4000자

```
毎日の一杯を、サイエンスに。

Note My Coffee は、コーヒーの抽出を「4つの数字」で記録するレシピノートです。
粉量・湯温・抽出時間・抽出量 — たった4つを入力するだけで、昨日の完璧な一杯を、
今日そのまま再現できます。

専門的なアプリは設定が多すぎる。メモアプリでは続かない。
Note My Coffee は、その間（あいだ）を埋めます。開いて30秒、ログインなしで
最初の一杯を記録できます。

■ こんな方に
・エスプレッソやハンドドリップの味を安定させたい
・「美味しかったあの一杯」を再現できずに困っている
・豆やレシピの記録をスマートに残したい
・自分のレシピをシェアしたい、人のレシピを試したい

■ 主な機能
◎ 4つの数字で記録 — 粉量・湯温・抽出時間・抽出量。スライダーで直感的に。
◎ SCA抽出ガイド — 各変数を上げ下げすると味がどう変わるか、プロの基準とともに表示。
◎ 内蔵ストップウォッチ — 抽出時間をその場で計測して記録に反映。
◎ 天気連動のヒント — 気温・湿度に合わせた抽出アドバイス。
◎ ログブック — すべての一杯を写真つきで振り返り、検索・絞り込み。
◎ シェアカード — 記録を美しいカードにして SNS でシェア。
◎ 発見フィード — ほかの人の公開レシピを見て、ワンタップで自分のノートに取り込み。
◎ もう一度淹れる — 過去のレシピをそのまま呼び出して再抽出。

■ はじめやすさ
最初の一杯はログインなしで記録。続けたくなったら Google または Kakao で
ログインすれば、すべての記録がクラウドに保存され、スマホでもPCでも同じ記録が
使えます。体験で残した記録も、そのままアカウントに引き継がれます。

■ 対応言語
日本語・한국어・English・繁體中文

コーヒーは、毎日の小さな実験です。
Note My Coffee で、その一杯一杯を、記録に変えましょう。
```

## スクリーンショット (생성 완료)

일본어 폰 스크린샷 **4장**을 생성했습니다(1080×1920). 앱이 실제로 일본어인
핵심 루프 화면만 담았습니다 — 둘러보기·프로필은 아직 한국어라 제외.

| 파일 | 화면 | 日本語 캡션 |
|------|------|------------|
| `phone-1-record-ja.png` | 기록 콘솔 | 4つの数字で、30秒で記録。 |
| `phone-2-sca-ja.png` | SCA 가이드 | 味の変化を、SCA基準でガイド。 |
| `phone-3-share-ja.png` | 공유 카드 | 記録が、一枚のカードになる。 |
| `phone-4-logbook-ja.png` | 로그북 | すべての一杯が、記録になる。 |

**재현 방법**: 리포지토리 루트에서 로컬 서버를 띄우고 Playwright로 캡처·합성합니다.
- 화면 캡처: `app.html`/`logbook.html`을 로드해 UI 텍스트를 일본어로 치환(기록·로그북),
  `store/android/src/screen-sca-ja.html`·`screen-share-ja.html` 목업(SCA·공유) → `src/cap-*-ja.png`.
- 파노라마 합성: `store/android/src/screens-ja.html`(4320×1920, 기기 프레임 + 이어진
  어두운 실사 배경 + 캡션)을 캡처해 1080×1920 4장으로 분할.
- 공유 카드는 `brew-card.js`의 `renderBrewCanvas(..., 'ja')`로 렌더한 `src/card-ja-story.png`.

(참고: 한글판 5장과 달리 둘러보기·프로필은 빠져 4장입니다. 커뮤니티 일본어화 후 추가 가능.)

## アップロード 체크리스트 (Play Console)

1. **스토어 등록정보**(기본 등록정보) → 상단 **언어 추가** → **日本語 – ja-JP** 선택.
2. 위의 **アプリ名 / 簡単な説明 / 詳細な説明** 붙여넣기.
3. **그래픽** 섹션에서 일본어 전용 **피처 그래픽**(`feature-graphic-ja.png`)과
   **폰 스크린샷**(일본어판)을 업로드. (업로드하지 않으면 기본 언어 자산이 그대로 노출됨.)
4. AI 생성 애셋 질문에는 기존과 동일하게 라벨 지정(이미지가 AI로 생성·합성됨).
5. 저장 → 검토 제출.

> 참고: 앱 내 언어(日本語)와 스토어 등록정보 언어는 별개입니다. 앱 UI 일본어화는
> 이미 프로덕션에 배포되어 있고(헤더 토글 日本語), 이 파일은 "스토어 페이지"의
> 일본어화를 위한 것입니다.
